# Assets Directory

## Resume File

To enable the resume download functionality, please add your PDF resume file to this directory with the following name:

**Pratyaksh_Mathur_Resume.pdf**

The resume modal in the portfolio application is configured to display and allow download of this file. Make sure the file name matches exactly for the functionality to work properly.

### File Requirements:
- File name: `Pratyaksh_Mathur_Resume.pdf`
- Format: PDF
- Location: `/assets/Pratyaksh_Mathur_Resume.pdf`

Once you add the PDF file, the resume tab will allow users to:
1. View the PDF inline in a modal
2. Download the PDF directly
3. Close the modal to return to the portfolio
